# 臺科大羽球社網站使用說明

臺科大羽球社官方網站提供社團介紹、社員申請、社課報名、行事曆、公告與常見問題等功能。

## 網站連結

[前往臺科大羽球社網站](https://ntustbc.github.io/)

## 網站功能

- **首頁**：查看社團近期資訊與網站主要功能。
- **關於我們**：認識臺科大羽球社、社課內容與活動資訊。
- **加入社團**：了解社員資格、會費與申請方式。
- **社課報名**：查看目前開放報名的社課日期並完成報名。
- **訊息公告**：透過行事曆查看社課、公告、活動及連續假期。
- **Q&A**：查詢常見問題與相關說明。

網站頁尾可切換中文或英文顯示。

## 註冊與登入

1. 點選網站右上方的「登入／註冊」。
2. 首次使用請建立帳號，並填寫 Email、密碼、姓名、學號、學校、系別及聯絡電話。
3. 註冊時可選擇是否申請成為本學期社員。
4. 已有帳號者可直接使用 Email 與密碼登入。

若忘記密碼或無法登入，請透過下方聯絡資訊與社團幹部聯繫。

## 申請成為社員

1. 註冊帳號時，或登入後前往「帳號設定」提出社員申請。
2. 選擇繳費方式，並依畫面填寫所需資料。
3. 送出申請後，可在帳號設定中查看審核狀態。
4. 幹部確認資料及繳費後，帳號會更新為正式社員。

正式社員可依網站公告的規則優先報名社課。

## 報名社課

1. 登入網站。
2. 前往「社課報名」。
3. 選擇開放報名的日期，確認時間、地點、名額及截止時間。
4. 送出報名後，可在頁面中查看報名狀態。

若社課名額已滿，系統會依規則安排候補；有名額釋出時將依候補順序遞補。

## 查看行事曆與公告

1. 前往「訊息公告」。
2. 使用上個月、下個月功能切換月份。
3. 行事曆會顯示社課、公告、活動與連續假期。
4. 點選有內容的日期，可查看時間、地點及備註等詳細資訊。

## 帳號設定

登入後可在帳號設定中：

- 查看社員與申請狀態。
- 修改姓名、學校、系別及聯絡電話。
- 調整通知偏好。
- 申請本學期社員資格。
- 登出或刪除帳號。
