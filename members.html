Members Dashboard

社員註冊名單

這裡會顯示透過 Firebase 註冊進來的社員帳號，方便你快速查看目前註冊數、信箱與最近登入時間。

這裡看的是註冊帳號，不是完整社員資料

如果你之後想再追蹤姓名、系級、社費或報名紀錄，我們可以繼續在 Firestore 往下擴充欄位與管理介面。

Overview

監看註冊狀態

這一頁只會在你登入後載入資料。若有設定管理員信箱，也會只讓指定信箱看到名單。

請先登入

先點右上角登入／註冊，之後這裡就會顯示社員名單。

學期預設 維護模式 社員名單 幹部名單 管理員名單 社課名單 行事曆 Q&A
Semester Defaults

本學期預設資料

集中管理學年度、入社繳費方式與每週社課時段。

系統會在 2/1、8/1 後首次開啟管理頁時自動切換學期並將社員轉為前社員；也可以在這裡手動調整。

Membership Registration

社員申請名額與期間

限制本學期可申請社員的人數，並設定開放及截止時間；非社員帳號仍可正常註冊。

Membership Payment

入社繳費資訊

這些資料會顯示在註冊及帳號資訊的轉帳／現金社費介面。

設定申請社員時可選擇的現金繳費地點或時段。

Weekly Classes

每週社課時間

可設定本學期每場社課的預設人數上限，以及不同社課時段與報名時間；套用到行事曆時會自動換算日期。

新增預設時段或行事曆社課時會自動帶入；下方各場社課仍可個別修改。

Maintenance Mode

網站維護模式

開啟後，一般使用者只會看到維護提示；已登入的管理員仍可正常瀏覽與操作網站。

Filter

社員名單篩選

依學年度、學期與身分類別篩選，下方名單及統計會同步更新。

Members

社員名單

名單分成「已申請成為社員（包含現金及轉帳）」與「有帳號但未申請社員」兩部分；展開後可修改基本資料、學年度與學期。

Club Officers

幹部名單

從既有註冊帳號新增幹部，或移除幹部身分。幹部可使用社員功能，但不會計入社員申請名額。

Filter

篩選幹部

可依姓名、學號、Email、學年度或學期篩選。

Administrators

管理員名單

從既有註冊帳號新增管理員，或移除管理權限。管理員不會計入社員申請名額。

Class Schedule

社課與公告行事曆

點選日期先查看內容；按「新增內容」或選擇既有項目後才會開啟編輯表單。
